## Hinweise

- Nach korrekter Eingabe bleibt die Lupe für die Browser-Sitzung geöffnet. Nach Schließen des Tabs wird der Code erneut abgefragt.
- Gleicher Code bei V1 und V2 derselben Animation.
- Die Codes stehen nicht im Klartext im Quelltext, sind aber mit etwas Aufwand aus dem Code ableitbar. Für den Unterricht reicht das als Sperre.
